# Dinos Mobile

Expo SDK 56 + React Native 0.85 모바일 앱.

## Commands

- pnpm dev:mobile (Expo dev server)
- pnpm lint (ESLint)
- pnpm check-types (TypeScript)

## Structure

- app/: Expo Router 라우팅 진입점 (로직 없음)
- src/features/: 기능별 모듈
- src/components/: 공통 UI
- src/hooks/: 공통 훅
- src/services/: API 클라이언트
- src/utils/: 유틸리티
