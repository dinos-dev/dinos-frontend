# Dinos Web

Next.js 16 + React 19 웹 앱.

## Commands

- pnpm dev:web (Next.js dev server)
- pnpm lint (ESLint)
- pnpm check-types (TypeScript)

## Structure

- app/: Next.js App Router (Server Components 기본)
- src/features/: 기능별 모듈
- src/components/: 공통 UI
- src/hooks/: 공통 훅
- src/services/: API 클라이언트
- src/utils/: 유틸리티
